# Lapidist
> (n) a skilled worker who cuts, polishes, and engraves precious stones and gems
---

I am building tools that help teams create accessible, sustainable user interfaces.

I'm Brett Dorrans, a principal frontend engineer and design-systems specialist with more than 15 years' experience across fintech, regulated SaaS and high-growth startups. I've led design-system architecture for enterprise platforms and contribute to the broader design-token standards community.
